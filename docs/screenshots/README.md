# Capturas da aplicação

Capturas geradas no AgendaFlow em execução local. Os dados, o salão e os perfis exibidos pertencem ao modo demonstrativo. As datas e os indicadores variam conforme o dia da captura.

| Tela | Rota e estado |
| --- | --- |
| [Início desktop](inicio-desktop.jpg) | `/`, página completa com hero, recursos e rodapé |
| [Início mobile](inicio-mobile.jpg) | `/`, viewport de 390 × 844 CSS pixels |
| [Catálogo desktop](catalogo-desktop.jpg) | `/estudio`, apresentação do Studio Bloom e catálogo |
| [Painel desktop](dashboard-desktop.jpg) | `/demo/painel`, indicadores e volume de agendamentos |
| [Agenda semanal desktop](agenda-semanal-desktop.jpg) | `/demo/agenda`, botão **Semana** selecionado |
| [Horários mobile](horarios-mobile.jpg) | `/agendar`, serviço e profissional escolhidos |
| [Confirmação mobile](confirmacao-mobile.jpg) | `/agendar`, após reservar com um perfil fictício |

Desktop capturado em viewport de 1440 × 960. As capturas de página inteira podem ter altura maior. O rodapé inclui a autoria em cada rota.

Para atualizar a galeria, inicie a demonstração sem variáveis Supabase, abra um contexto limpo do navegador, use os tamanhos indicados e percorra os estados da tabela. Aguarde carregar o catálogo e concluir a animação inicial do gráfico. Salve as imagens como JPEG, mantendo nomes e textos alternativos usados no README.
